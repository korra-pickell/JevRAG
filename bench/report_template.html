Method

  • JevRAGRank: bge-base-en-v1.5 dense retrieval selects candidates; decider-2b answers one typed score question per candidate (five levels from “irrelevant” to “fully answers”).
  • JevRank: no embeddings. Batched choice questions over groups of documents keep the likeliest few per group, round after round, then a score round ranks the finalists.
  • Baselines: BM25 (bm25s), dense only, dense → bge-reranker-base, dense → Qwen3.5-2B-Base prompted for a 0–4 rating (the model decider-2b was fine-tuned from).
  • Jev settings were tuned on SciFact train and NFCorpus dev; test splits were run once. Latency is measured one query at a time after five warm-up queries, with no response cache.
